SheetSort — College Data Processing Platform
PROJECT SYNOPSIS & TECHNICAL BRIEF
An Automated, Air-Gapped Desktop Suite for Academic Data Cleaning, Standardization & Multi-Sheet Excel Operations
1. Executive Summary & Abstract

Educational institutions process tens of thousands of student records every semester across exam cells, admissions, placement cells, and academic departments. These datasets arrive in heterogeneous, unstructured formats riddled with formatting discrepancies, irregular headers, duplicate entries, inconsistent phone numbers, and mixed date styles. SheetSort is an enterprise-grade, privacy-first desktop application developed to automate college data transformations. Operating strictly within an air-gapped local environment, SheetSort replaces hours of error-prone manual spreadsheet wrangling with a resilient, multi-step pipeline—incorporating heuristic schema detection, automated cleaning rules, multi-level sorting, deduplication, departmental splitting, and a reusable "Recipe" workflow engine.

2. Problem Statement & Motivation

Academic Administrative Bottlenecks

Departmental offices receive attendance sheets, mark lists, and roster files with inconsistent formatting (e.g. 1-4 banner title rows, random column casings). Staff spend substantial manual hours aligning columns and sorting rosters.

Data Integrity & Student Privacy Risks

Using cloud-based conversion utilities exposes confidential student PII (Roll Numbers, phone numbers, caste categories, marks). Furthermore, unvetted Excel files are vulnerable to spreadsheet formula injection attacks.

3. Objectives & Technical Scope
  • Zero-Latency Local Execution: Process up to 100,000 rows (50 MB) entirely on-premise without cloud transmission.
  • Autonomous Schema Recognition: Heuristically detect header offsets and infer specialized column data types (ID, Date, Email, Phone, Numeric).
  • Reusable Recipe Automation: Enable administrative staff to record and replay end-to-end transformation pipelines in one click.
  • Academic Department Splitting: Automatically divide centralized university rosters into department-wise worksheets in a single output workbook.
  • Compliance & Accountability: Maintain a tamper-evident SQLite audit log tracking every data action, row count, and exported file.
4. System Architecture & Modular Pipeline
Stage Module / Service Technical Responsibilities & Operational Logic
Stage 1: Ingestion upload_service.py Enforces 50 MB / 100k row caps; verifies magic bytes (PK for .xlsx, \xd0\xcf\x11\xe0 for .xls); sanitizes input streams.
Stage 2: Inference schema_detection.py Scans top 5 rows for string density to locate true header row; infers normalized schemas and detects IDs, emails, and phone patterns.
Stage 3: Cleansing data_cleaning.py Applies 8 vectorized transformations: whitespace trimming, header normalization, regex phone parsing, DD-MM-YYYY date coercion, empty row/col purging.
Stage 4: Organizing sorting.py & filtering.py Executes multi-column priority ordering (including custom categorical orders like CSE > IT > ECE) and complex compound Boolean filters.
Stage 5: Integrity deduplication.py Executes exact duplicate row pruning and configurable fuzzy near-duplicate matching over selected key attributes.
Stage 6: Distribution splitting.py Segments master DataFrames by unique values of a split column, sanitizing Excel sheet names to legal 31-character strings.
Stage 7: Export export_service.py Builds styled OpenPyXL workbooks with bold frozen headers, auto-filters, auto-fitted columns, safe formula escaping, and an executive Summary sheet.

6. Security Architecture & Penetration Testing Audit

Prior to institutional deployment, SheetSort underwent a comprehensive security audit identifying and fixing 8 distinct vulnerability vectors:

Vulnerability Vector Severity Attack Scenario & Impact Implemented Defense Mechanism
CSV / Formula Injection RESOLVED High Student names containing =cmd|' /C ...'!A1 executing malicious shell payloads on Excel opening. safe_excel_value() prepends apostrophes (') to strings starting with =, +, -, or @.
ReDoS (Regex Denial of Service) RESOLVED Critical Malicious filter patterns (e.g. (a+)+$) triggering catastrophic CPU backtracking and UI freezing. Enforced literal string searching with regex=False across all search and containment filters.
File Signature Spoofing RESOLVED Critical Renaming executable malware to .xlsx or .xls to bypass extension verification. Implemented magic-byte inspection validating ZIP headers (PK) and OLE2 compound headers.
Path-Traversal in Storage RESOLVED Medium Arbitrary environment database redirection targeting privileged operating system directories. Implemented get_safe_db_path() constraining all SQLite operations to verified safe paths.
Localhost Network Isolation RESOLVED High Exposing administrative spreadsheets over the campus LAN or Wi-Fi subnets. Desktop launcher binds exclusively to loopback 127.0.0.1; usage telemetry strictly disabled.
